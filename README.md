A modern, responsive personal portfolio website built for **Jusuf Fathan Nuradly** (*Junior Developer*). Designed with a sleek **Dark Glassmorphism** aesthetic and **Electric Blue** accents, this web application highlights technical skills, development workflow, and a curated showcase of web and mobile applications.

---

## ✨ Key Features

- **Modern Dark Glassmorphism UI:** Crafted with translucent surfaces, subtle borders, and electric blue highlights for a clean, contemporary developer aesthetic.
- **Smooth Interactive Animations:** Powered by **Framer Motion** for fluid page transitions, scroll-triggered reveals, and micro-interactions.
- **Fully Responsive Design:** Optimized for seamless viewing across desktop, tablet, and mobile devices using **Tailwind CSS**.
- **Structured 4-Step Workflow Section:** Communicates the end-to-end development process from concept and UI/UX design to coding and deployment.
- **Curated Project Showcase:** Interactive gallery displaying 7 featured web and mobile projects across React, JavaScript, and Flutter.
- **Direct Contact Integration:** Dedicated contact section to streamline collaboration, freelance inquiries, and recruitment opportunities.

## ⚙️ Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com/<your-username>/personal_branding.git
cd personal_branding
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173` (or the local URL displayed in your terminal).

### 4. Build for Production
```bash
npm run build
```
